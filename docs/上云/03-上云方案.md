> 历史材料：本轮保留 Java + MySQL + Redis，云交付使用数据库 outbox 与三容器制品；本文件旧 CloudBase/默认账号/直接初始化建议不再作为执行依据。当前以 [阿里云测试手册](../ALIYUN-STAGING-RUNBOOK.md) 和 [生产验收](../PRODUCTION-READINESS.md) 为准。

# 上云方案（推荐：微信云开发「云托管」）

## 一、结论

项目是「传统自建后端」架构（Java 694 文件 + MySQL 41 表 + 事务/锁/幂等），与云开发「原生模式（云函数 + 文档库）」不匹配。**正确路线是用云开发的「云托管」跑现有 Java 后端**，几乎零重构。

| | 现有项目 | 云开发·原生 | 云开发·云托管 |
|---|---|---|---|
| 后端 | Java Spring Boot 694 文件 | Node 云函数，要重写 | 任意语言容器，直接上 ✅ |
| 数据库 | MySQL 8 + 事务 + 唯一索引 | 文档型 JSON | 云数据库 MySQL 版 |
| 并发防超卖 | Redisson + DECR + DB 唯一索引 | 无对应，要重写 | 原样保留 |
| 改造量 | — | 巨大（重做） | ≈ 3 处小改 |

> 补充：微信云开发只覆盖**计算（云托管/云函数）+ 数据库（文档/MySQL）+ 存储 + 静态托管**；**Redis、RocketMQ、CDN 没有云开发原生产品**，需用腾讯云侧产品补齐，与云托管同 VPC 内网互通。

## 二、三条路线对比

| 路线 | 做法 | 改造量 | 适用 |
|---|---|---|---|
| **A 云托管（推荐）** | Java 容器上云托管；MySQL 用云数据库；文件用云存储；admin 用静态托管；Redis 接腾讯云 | 小 | ✅ 现在 |
| B 原生云开发重构 | 云函数 + 文档库重写全部 | 巨大 | ❌ |
| C 腾讯云 CVM 自建 | 现有 docker-compose 搬一台云服务器 | 极小，但自己运维 | 想要完全掌控 |

**以下按路线 A 展开。**

## 三、完整配置清单

### 3.1 前置资质（一次性）
1. 小程序**主体认证**（企业主体，否则支付/云调用用不了）。AppID 已有 `wxd9bd556ad0c77104`。
2. 开通云开发，建环境，拿**环境 ID**。
3. 环境选**「按量付费」**（静态托管/云托管/云存储都要求按量付费）。
4. **域名 ICP 备案** + HTTPS（request 域名、支付回调、云托管域名都要）。
5. 微信支付商户号（若真实收费）：mchid / API v3 密钥 / 商户证书。

### 3.2 云开发控制台配置
- **云托管**：新建服务，构建方式 Dockerfile（复用 `deploy/Dockerfile.server`）；容器端口 `8080`；规格建议 **1C2G 起**（Java 起步 ~512MB）；扩缩容策略见坑点 1；配环境变量（见 3.3）。
- **云数据库 MySQL**：建库 `yoyi_pilates`，字符集 `utf8mb4`；导入 `database/schema.sql` + `init_data.sql`；与云托管同环境**内网直连**。
- **云存储**：开通，建路径存头像/图片（替换本地 uploads）。
- **静态网站托管**：`admin` 构建产物 `dist/` 上传；配索引文档 `index.html`。⚠️ 不能做 API 反代，admin 前端要改 baseURL + 配 CORS。
- **腾讯云 Redis（云开发外）**：后端强依赖 Redis，云开发没有托管 Redis，买一个与云托管**同 VPC** 内网互通。
- **RocketMQ（可选）**：体验期 `MQ_TYPE=memory`；生产用腾讯云 TDMQ/CMQ。**别把 RocketMQ 塞进云托管容器**。

### 3.3 后端要改的 3 处代码
1. **文件上传改云存储（必须）**：`FileController` 现在写本地 `./uploads`。改法：小程序端 `wx.cloud.uploadFile` 传云存储、后端只存 URL；或后端接 COS/云存储 SDK `putObject` 返回外链。删掉 `Files.createDirectories` + `transferTo`。
2. **小程序 `app.js`**：`baseUrl` 改云托管 HTTPS 域名；`useMockLogin:false`；删 `mockCode`。`project.config.json` 生产开 `urlCheck`。
3. **admin `src/utils/request.js`**：`baseURL:'/'` 改云托管 API 域名；后端 `CORS_ALLOWED_ORIGINS` 填 admin 静态托管域名。

**后端环境变量（云托管控制台注入）**：
```
SPRING_PROFILES_ACTIVE=prod
MYSQL_HOST/PORT/USER/PASSWORD      # 云数据库 MySQL
REDIS_HOST/PORT/PASSWORD           # 腾讯云 Redis
JWT_SECRET                         # openssl rand -base64 48
WX_APPID=wxd9bd556ad0c77104
WX_SECRET=                         # 真实登录必填
WX_MOCK_LOGIN=false
PAY_MOCK_ENABLED=true              # 体验期 true；真收费改 false
WX_PAY_*                           # 真支付才填
WX_PAY_NOTIFY_URL=https://域名/api/payment/wechat/callback
MQ_TYPE=memory                     # 生产改 rocketmq/TDMQ
CORS_ALLOWED_ORIGINS=https://admin域名
```

### 3.4 小程序端配置
1. `app.js` 改 baseUrl、关 mock。
2. 微信公众平台 → 开发 → 服务器域名：云托管 API 域名加 **request 合法域名**；仍走后端上传加 **uploadFile**；云存储 fileID 下载走 **downloadFile**。
3. 用 `wx.cloud.uploadFile` 时 `app.js` 里 `wx.cloud.init({ env: '环境ID' })`。

### 3.5 域名 / HTTPS / 支付回调
- 云托管绑定自定义域名 + HTTPS 证书。
- **支付回调 notify-url** 指向公网 HTTPS 域名，能通过微信支付 V3 平台证书验签。
- request 域名与回调域名都要**备案**。

### 3.6 数据迁移
- 本地 `uploads/` 历史图片迁云存储，批量更新库中 URL。
- 云数据库开自动备份。

## 四、关键坑点
1. **定时任务 vs 缩容到 0**：`PilatesScheduler` 6 类任务依赖常驻进程。要么云托管最小副本=1（失去零成本）；要么拆到「云函数 + 定时触发器」调后端接口触发。
2. **本地文件易失**：不改 3.3-1，头像图片上线即丢。
3. **mock 开关**：上线必须 `WX_MOCK_LOGIN=false`、`PAY_MOCK_ENABLED=false`，否则假 code 可登录、免费买课包。
4. **Redis 不在云开发里**：另配且必须内网互通。
5. **RocketMQ 别塞云托管**。
6. **urlCheck + 合法域名**：漏配 = 小程序所有请求失败。

## 五、落地顺序（4 步）
1. **体验期跑通**：开按量付费环境 → 云托管上后端（开 mock、memory MQ）→ 云数据库导数据 → 腾讯云 Redis → 小程序改 baseUrl → 跑通登录/买课包/预约/签到闭环。
2. **接真实能力**：关 mock、填 WX_SECRET、接真实支付或继续 mock、配订阅消息模板 ID。
3. **前端上云**：admin 上静态托管 + 改 baseURL + CORS；文件上传切云存储。
4. **生产加固**：备案 + 自定义域名 + HTTPS、定时任务方案定案、云数据库备份、支付回调验签、线上复验 `BookingConcurrencyTest` 并发。
