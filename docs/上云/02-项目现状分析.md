# 项目现状分析（上云视角）

## 一、项目定位

优仪普拉提（Yoyi Pilates）—— 普拉提工作室数字化运营系统：
小程序（用户端 + 教练端）+ Vue3 Web 管理后台 + Java 后端，覆盖获客、约课、课包、支付、训练记录、评价、营销、统计的完整闭环。

## 五、关键机制（上云不能破坏的）

1. **统一响应** `Result{code,message,data}`，0=成功；异常抛 `BusinessException`。
2. **预约防超卖四道防线**：@Idempotent(Redis SETNX) → Redisson 锁 → Redis DECR(<0 回补) → DB 条件 UPDATE + 唯一索引。**强依赖 Redis。**
3. **支付回调幂等四道防线**：out_trade_no 唯一 → payment 乐观推进 → order 乐观推进 → user_package 唯一。
4. **事件总线**：`eventPublisher.publish(...)`，dev=内存、prod=RocketMQ，消费须幂等。
5. **认证**：JWT + Redis 登录标记（支持登出吊销）；教练走 admin-login + CoachBinding。
6. **业务规则走 `system_config` 表**（取消 4h、预约截止 30min、积分规则等，后台可改）。
7. **定时任务 6 类**：关单 / 课程完成 / 开课提醒 / 会员到期提醒 / 过期处理 / 库存对账。

## 六、上云卡点清单

| 卡点 | 现状 | 影响 |
|---|---|---|
| 后端位置 | 跑在 Mac `192.168.3.177:8090` | 别人手机访问不到，只能局域网/调试用 |
| baseUrl 硬编码 | `app.js` 写死内网 IP | 同上 |
| mock 开关 | dev 默认 mock 登录 + mock 支付 | 上线不关 = 假 code 可登录、免费买课包 |
| 本地文件存储 | `./uploads` 目录 | 云托管容器易失，图片会丢 |
| Redis 依赖 | 分布式锁/库存/幂等/登出都靠它 | 云开发无托管 Redis，需另配 |
| RocketMQ | prod 默认要 | 云开发无，需 TDMQ 或先 memory |
| 域名/备案 | 无 | 小程序正式版 request 域名必须 HTTPS+备案 |
| 定时任务 | 进程内 @Scheduled | 云托管缩容到 0 后全停 |
