# 微信云开发文档汇总（已抓取要点）

> 来源：微信官方文档 developers.weixin.qq.com。抓取日期 2026-10-15。
> 注意：这些页面均为「能力总览页」，只讲概念/优势/导航，**不含完整代码或 API 参数**——具体用法在各自子页面（见 05 待抓清单）。

---

## 一、快速入门（小程序云开发）

1. 装「微信开发者工具」；注册小程序拿 AppID（开发管理 → 开发设置）。
2. 新建小程序项目 → 填 AppID → **后端服务选「微信云开发」** → 同意服务条款。
3. 工具栏点「云开发」开通并新建**环境**：
   - 每个环境**相互隔离**，有唯一环境 ID，各自独立的数据库/存储/云函数配置。
   - **首个环境自动成为默认环境**。
4. 模拟器体验基础能力演示。

**补充入口**：
- **Skill / MCP 辅助开发**：支持 MCP 的 AI IDE 可用对话方式查数据、查云函数日志、排查 `wx.cloud.callFunction`。
- **低代码编辑器**：模板来源选「微搭」，拖拽组件搭建。

---

## 二、云数据库

- 支持**文档型 + MySQL** 两种数据库。
- 卖点：多端 SDK、类型校验、关联关系、自动生成 CRUD 代码、内置 CMS、AI 数据分析。
- 权限三种：**简易权限配置 / 安全规则 / 旧版权限**。
- 核心 API（入口）：`database → collection/command/Geo/serverDate/RegExp/runTransaction`；`Collection → where/limit/orderBy/get/update/remove/count/add/watch`。
- 对你的意义：**你的后端用的是 MySQL 8 + MyBatis-Plus，对应这里的「云数据库 MySQL 版」**，41 张表原样导入即可。

## 三、存储（云存储）

- 存图片/视频等非结构化数据，控制台可视化管理。
- 支持文件夹、上传/删除/移动/下载/搜索（前缀名 + 子目录搜索）。
- `image`、`audio` 组件可**直接传云文件 ID**。
- 权限：基础权限 + 高级安全规则。
- 对你的意义：**替换后端现在的本地 `./uploads` 目录**（头像/图片），云托管容器无状态，本地文件会丢。

## 四、云函数

- 服务器端函数，跑在 Node.js，函数间可互调、可分开部署。
- **小程序端调用时参数自动注入用户 openid**，微信已鉴权，不用再校验。
- 对你的意义：**不适用**——你的后端是 Java，不该重写成 Node 云函数；但可用来放「定时触发器」跑定时任务。

## 五、云托管（CloudBase Run）★ 你的主战场

- **云原生容器服务，支持任意语言/框架**，面向代码使用、免运维。
- 特性：天然鉴权（容器内免鉴权取 openid/unionid）、常驻运行、自动扩缩容、**缩容至 0**、**20 秒扩容**、一行 `cloud.callContainer` 调用、一键部署。
- 与云函数对比：单实例**多**并发（云函数单并发）、任意语言、常驻、按 CPU/内存/流量/构建时长计费。
- 适用场景：传统业务后台迁移、流量波动型业务。
- 对你的意义：**这就是跑你现有 Java Spring Boot 后端的地方**。

## 六、云调用

- 基于云函数调微信开放接口，**无需换取 access_token**。
- 要求 `wx-server-sdk >= 0.4.0`。
- **必须在云函数目录 `config.json` 声明**：
  ```json
  { "permissions": { "openapi": ["subscribeMessage.send"] } }
  ```
- 配置有 **10 分钟缓存**（改后报 `-604101` 等 10 分钟）。
- 调用形态：`cloud.openapi.<类别>.<方法>(...)`，如 `cloud.openapi.subscribeMessage.send(...)`。
- **频率限制 10 万/分钟**。
- 对你的意义：**可选优化**——你后端现在用 `WxMpClient` 自己换 access_token，可后续迁到云调用免维护 token。

## 七、CMS 内容管理 ⚠️

- **官方已停止维护，建议改用云后台数据管理能力。** 新项目别基于它做。

## 八、静态网站托管

- 托管 HTML/JS/CSS/图片等，自带 CDN。
- **仅「按量付费环境」可开通**。
- 每环境一个默认域名，可绑自定义域名。
- 小程序 `<web-view>` 可免配业务域名直接打开。
- 配置：自定义域名、索引文档、缓存时间、IP/Referrer 黑白名单、频率限制。
- **注销不可恢复**。
- 对你的意义：托管 Vue3 管理后台（`admin/dist/`）构建产物；注意它**不能做 API 反向代理**，后台前端要改 baseURL 指向云托管域名。
