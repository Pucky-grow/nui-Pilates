## 1. 项目概述

「优仪普拉提（Yoyi Pilates）」是一套面向普拉提工作室的数字化运营系统，覆盖 **获客 → 登录 → 浏览课程/教练 → 购买课包 → 预约 → 签到 → 上课 → 训练记录 → 评价 → 积分 → 续费 → 统计** 的完整商业闭环。

系统由三端组成：

| 端 | 技术栈 | 服务对象 |
|---|---|---|
| **微信小程序**（本评审对象） | 微信原生小程序（WXML/WXSS/JS），米白/奶油/鼠尾草绿品牌主题 | 学员、教练 |
| Web 管理后台 | Vue 3 + Vite + Element Plus + Pinia + ECharts | 管理员、教练 |
| Java 后端 | Spring Boot 3.2 + MyBatis-Plus + MySQL 8 + Redis + Redisson | 三端共用 |

小程序又分为两部分：

- **用户端（主包）**：面向学员，4 个底部 Tab（首页 / 课程 / 预约 / 我的）。
- **教练端（分包 `coach-end/`）**：面向教练，独立工作台，与用户端解耦。

## 2. 系统角色与权限

| 角色 | 身份载体 | 登录方式 | 系统角色 | 小程序界面 |
|---|---|---|---|---|
| 学员 | `user`（微信 openid） | 微信一键登录 | MEMBER | 用户端 4 Tab |
| 教练 | `sys_user` + `coach`（可绑微信） | ① 账号密码 ② 绑定微信后一键登录 | COACH | 教练工作台（分包） |
| 管理员 | `sys_user` | 账号密码 | ADMIN | Web 后台（不用小程序） |

**权限要点**
- 学员只能操作自己的预约/课包/训练/评价。
- 教练只能查看、操作**自己授课**的排课和学员（数据权限按 `coachId` 隔离），并可给自己排课、编辑自己负责课程的展示信息。
- 教练登录后小程序返回 `roles` 含 `COACH`，据此在「我的」页显示「教练工作台」入口；账号密码登录的教练另存 `coachToken`。

**登录态保持**：小程序 token 有效期 2 小时；前端用 `loginAt` 时间戳校验，超时自动清除登录态并跳登录页；后端 `yoyi.jwt.mp-ttl=7200000`（毫秒）。

## 3. 小程序技术架构

- **框架**：微信原生小程序（无跨端框架），WXML/WXSS/JS，`libVersion: 2.33.0`。
- **分包**：主包 `pages/`（29 页）+ 教练端分包 `coach-end/`（10 页），`lazyCodeLoading: requiredComponents` 按需注入。
- **请求封装**：`utils/request.js` 统一封装 `wx.request`，自动注入 `Authorization: Bearer <token>`，统一处理 `{code,message,data}` 返回、40100 登录过期静默重登、异常 Toast；另提供 `upload()`（`wx.uploadFile` 上传头像）。
- **接口出口**：`services/api.js` 集中定义后端接口（用户端）、`coach-end/api.js`（教练端）。
- **后端地址**：`app.js` 的 `ENV` 统一配置（`baseUrl` + `useMockLogin` + `mockCode`），开发/生产切换改一处即可。
- **后端依赖**：MySQL 8、Redis（Redisson）、MQ（开发内存总线 / 生产 RocketMQ）、微信登录 `code2session`、微信支付 V3（含 mock 开关）。

## 5. 核心业务流程

### 5.1 登录与授权

**微信登录（学员）**
1. 登录页需先勾选「已阅读并同意《用户协议》《隐私政策》」。
2. 前端 `wx.login()` 获取临时 `code`（开发态 `useMockLogin=true` 用固定 `mockCode` 模拟稳定用户）。
3. `POST /api/auth/wx-login` 后端 `code2session` 换取 `openid` → 查/建用户（首登自动建会员档案）→ 签发 JWT。
4. 新用户首次登录，前端 Toast 引导去「我的」完善头像昵称。

**账号密码登录（教练）**
- 走 `POST /api/auth/admin-login`；ADMIN 角色被拦截（提示用 Web 后台），COACH 角色存 `coachToken` 进教练工作台。

**微信头像 / 昵称 / 手机号授权（现行微信规范）**

| 信息 | 授权方式 | 说明 |
|---|---|---|
| 头像 | `open-type="chooseAvatar"` | 点击头像弹出微信头像选择器，可"使用微信头像"；临时文件上传后端 `/api/upload` 持久化 |
| 昵称 | `input type="nickname"` | 输入框自动带出微信昵称快速填写 |
| 手机号 | `open-type="getPhoneNumber"` | 弹出手机号授权，新版 `code` 接口换取手机号（后端 `getuserphonenumber`） |

> 说明：微信已下线"一次性授权同时拿头像+昵称"的 `getUserProfile`，现行规范为上述三个独立交互。

### 5.2 预约（FREE 模式，默认）

- 默认 `booking.paymentMode=FREE`：会员**无需课包**直接预约、不扣课时、不产生订单/流水（PACKAGE 模式保留可切换）。
- 流程：课程详情/首页 → 选排期 → 预约确认页（FREE 模式直接确认，无需选课包）→ 提交。
- **防超卖四道防线**（后端）：`@Idempotent` 防连点 → Redisson 分布式锁（scheduleId）→ Redis DECR 预占库存 → DB 事务条件 UPDATE + 唯一索引。
- 预约规则（`system_config` 可配）：免费取消时限 4h、预约截止 30min、每日预约上限 3 次。
- 取消：同事务释放座位；超时取消按规则扣课时（PACKAGE 模式）。

### 5.3 购买课包与支付（当前为 mock 支付）

- 流程：课包商城 → 课包详情（选优惠券/积分抵扣）→ 下单 → 支付。
- **体验期 `pay.mock-enabled=true`**：前端 `createPay` 返回 `mock=true` 时自动走 `mock-pay`，无需真实扣款即完成"课包到账"，跑通闭环。
- 正式收费时置 `false` 并接入微信支付 V3（回调幂等四道防线：`out_trade_no` 唯一 → 支付单乐观推进 → 订单乐观推进 → 课包发放唯一索引）。
- 课时变动一律写 `package_credit_log` 流水，余额 = 流水累计，可对账。

### 5.4 私教预约

选教练 → 选训练目标 → 选可用时间（教练可约时段 = 工作时间 − 排课 − 请假）→ 确认预约。

### 5.5 签到

- 学员端：扫码签到（核销码）或手动确认签到。
- 教练端：可在学员列表代签到。

### 5.6 训练记录与身体评估

- 教练上完课填写训练记录（目标/内容/强度/反馈/建议，支持模板）。
- 学员在「训练」页查看记录与统计（累计次数/时长/本月/连续天数 + 趋势）。
- 「身体评估」记录身高/体重/体脂/围度/体态观察，并展示趋势。

### 5.7 课程评价

学员对已上课程评价（课程/教练/环境三维评分 + 文字），评分回写教练评分重算；「我的评价」可查看。

### 5.8 积分与优惠券

| 项 | 规则 |
|---|---|
| 积分获取 | 注册 +50、消费 1 元 +1、签到 +5、评价 +20 |
| 积分使用 | 100 积分抵 1 元（下单抵扣） |
| 优惠券 | 新人券/满减券/折扣券/私教券；领券、下单核销、关单退回、限购、库存 |

### 5.9 邀请好友

我的邀请码 → 好友绑定邀请码 → 好友首购时触发邀请奖励（积分，`points.invite` 配置）。

## 6. 用户端页面详解

### 6.1 登录页 `pages/login/login`
- 品牌区 + **协议勾选**（《用户协议》《隐私政策》链接，未勾选不允许登录）。
- 微信一键登录（学员）、账号密码登录（教练）。
- 已登录且未超时自动跳过直接进首页。

### 6.2 首页 `pages/index/index`
- Banner 轮播（后台可配，可跳课程/课包/文章/链接）。
- 快捷入口：立即预约 / 私教预约 / 购买课包 / 教练团队。
- 新人体验课专区（限购一次）、今日课程、热门课程、教练团队、普拉提知识、工作室地址入口。

### 6.4 教练 `pages/coach-list` + `coach-detail`
- 列表：头像/姓名/职位/从业年限/擅长/评分。

### 6.5 私教预约 `pages/private-booking`
- 教练 → 训练目标 → 时间 → 确认 四步。

### 6.6 课包商城 `pages/package-list` + `package-detail`
- 课包类型：次卡/期限卡/私教课包。

### 6.8 预约 `pages/booking` + `booking-confirm` + `booking-detail` + `checkin`

- 评估记录 + 围度/体重趋势。

### 6.11 课程评价 `pages/review`
- 创建评价（三维评分 + 文字）、我的评价列表。

### 6.12 优惠券 / 积分 `pages/coupon` + `pages/points`
- 领券中心、我的券；积分余额、流水。

### 6.13 优仪课堂 `pages/article` + `article-detail`
- 分类、列表、详情；点赞、收藏。

### 6.14 消息中心 `pages/message`
- 站内消息列表、未读数、标记已读/全部已读。

### 6.15 意见反馈 / 邀请 `pages/feedback` + `pages/invite`

- 会员等级、累计训练/积分/累计消费。
- 入口：我的预约/课包/训练/评估/评价/优惠券/积分/消息/邀请/反馈。
- 教练工作台入口（教练身份）；当前登录身份、切换账号、退出登录。

### 6.17 关于 / 协议 / 隐私 `pages/about` + `agreement` + `privacy`
- 工作室信息、一键导航、联系客服。
- 用户协议、隐私政策正文（当前为占位文本，上线前需替换为法务确认稿）。

## 9. 小程序调用的主要后端接口

**认证/用户**
- `POST /api/auth/wx-login`、`POST /api/auth/admin-login`、`POST /api/auth/logout`
- `GET /api/auth/me`、`PUT /api/auth/profile`、`POST /api/auth/bind-phone`
- `POST /api/upload`（头像上传）

**公开浏览**
- `GET /api/home`、`GET /api/banners`、`GET /api/studio`
- `GET /api/courses[/{id}]`、`GET /api/course-categories`、`GET /api/course-schedules[/{id}]`
- `GET /api/coaches[/{id}]`、`GET /api/coaches/{id}/available-slots`
- `GET /api/packages[/{id}]`、`GET /api/articles[/{id}]`、`GET /api/article-categories`

**预约/签到**
- `POST /api/bookings`、`DELETE /api/bookings/{id}`、`GET /api/bookings/{id}`、`GET /api/my/bookings`
- `POST /api/attendance/check-in`、候补：`/api/waitlist/...`

**课包/订单/支付**

## 11. 安全与合规

- **认证**：JWT + Redis 登录态标记（支持登出吊销）；接口级权限 `@RequiresPerm`。
- **数据权限**：教练仅见自己授课数据。
- **隐私**：手机号脱敏展示（138****8888）；`user_privacy` 控制学员隐私字段对教练的可见性。
- **合规**：登录页强制勾选《用户协议》《隐私政策》；小程序后台需配置「用户隐私保护指引」。
- **幂等/限流**：预约/支付多道幂等防线；登录失败限流（同账号 5 分钟 10 次）。
- **CORS**：可配置白名单（生产收紧）。
