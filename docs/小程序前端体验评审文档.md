# 优仪普拉提 · 小程序前端体验评审文档

> 用途：从「真实普拉提工作室软件」视角，评审当前小程序各页面的展示是否合适、登录流程是否顺畅、哪里繁琐，供评审与修改。
> 生成时间：2026-10-12
> 当前业务定位：**免费预约为核心**（会员不购课包即可约课），课包/支付/营销为次要暂缓项。

---

## 一、整体结论

当前小程序**功能覆盖已经很全**（39 页），但存在一个贯穿性问题：**系统是"全功能商业版"的形态，而当前业务定位是"免费预约闭环"**，导致不少页面/入口在现阶段的运营下显得**冗余、误导或繁琐**。

核心矛盾集中在三点：
1. **课包/购买/支付相关入口仍在首页和"我的"里高频露出**，与"免费预约"定位冲突，容易让新用户困惑"到底要不要买课包"。
2. **首页信息过载**（9 个区块），预约这条核心路径反而不够突出。
3. **登录后资料完善、教练端入口等关键动作引导不足**，用户/教练要靠自己摸索。

## 二、登录流程评审

### 2.1 现在是怎么登录的

1. 打开小程序 → 登录页。
2. 用户**先勾选**「已阅读并同意《用户协议》《隐私政策》」。
3. **微信一键登录**（学员）或 **账号密码登录**（教练/管理员）。
4. 微信登录后进首页；新用户弹 toast「去『我的』完善头像昵称」。
5. 教练第一次需用**账号密码**登录，进教练工作台后可绑定微信，之后才能微信一键登录。

### 2.2 繁琐 / 不合适点

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | 新用户登录后头像昵称为空，仅靠一条 toast 提示，**没有落地引导** | 用户不知道去哪改、为什么要改；头像长期是"优"字占位 | 新用户首次登录后，**直接进入一个"完善资料"弹层/半屏**（点头像换微信头像 + 填昵称），一步到位 |
| 2 | 协议勾选与登录按钮在同一屏，**多一步勾选** | 合规必须，但可优化交互 | 保留合规，但可把协议做成**登录按钮下方的小字说明 + 勾选默认展开**，减少视觉负担 |
| 3 | 教练**第一次必须账号密码**，且绑定微信入口藏在工作台里 | 教练上手路径长 | 教练登录页给出明确提示"教练请用账号密码登录，首次登录后绑定微信即可扫码进" |
| 4 | 账号密码登录框始终展示在登录页，学员大概率用不到 | 页面略杂乱 | 学员默认只见"微信一键登录"，账号密码收进"教练/员工登录"折叠入口 |

## 三、用户端逐页评审（4 Tab）

### 3.1 首页（`index`）

**当前展示**：品牌头部 → Banner 轮播 → 快捷入口 4 个（立即预约/私教预约/我的预约/教练团队）→ 新人体验专区（带"立即购买"）→ 今日课程 → 热门课程 → 教练团队 → 普拉提知识 → 工作室地址。

**评审**：
- ✅ 今日课程/热门课程/教练团队用横向滚动卡片，符合小程序习惯，信息清晰。
- ❌ **信息过载**：9 个区块一屏拉不完，核心的"约课"被淹没在中间。
- ❌ **新人体验专区带"立即购买"**：当前是免费预约定位，这个购买入口**直接冲突**，且会让用户误以为要先买课包才能约课。
- ❌ 快捷入口里"立即预约"和"我的预约"含义重叠（一个是去课程列表，一个是去我的预约），图标还都是同一个 booking.png。

**建议**：
- 首页收敛为：Banner → 预约入口（突出）→ 今日课程 → 热门课程 → 教练团队 → 文章 → 地址；**弱化/移除"立即购买"**（除非该课包确实是当前主推）。
- 快捷入口调整为「预约课程 / 私教预约 / 教练团队 / 我的课表」，避免"立即预约 vs 我的预约"混淆。

### 3.2 课程 Tab（`course` + `course-detail`）

**当前展示**：日期/时段/难度筛选 → 课程卡片（名称/时间/教练/教室/时长/剩余名额/消耗课时）→ 详情（介绍/适合人群/训练重点/注意事项/近期排期/评价）。

**评审**：
- ✅ 筛选维度合理，卡片信息齐全。
- ⚠️ 卡片上的"消耗课时"在**免费预约模式下是无意义字段**，会再次暗示"要课时"。
- ⚠️ 课程详情里"近期排期"直接给了排期列表，但点击后进入预约，路径 OK。

**建议**：FREE 模式下，课程卡片**隐藏"消耗课时"**（或改为"免费预约"标签），从视觉上强化"免购课直接约"。

### 3.3 预约 Tab（`booking` + `booking-confirm` + `booking-detail` + `checkin`）

**当前展示**：我的预约列表（按状态筛选）→ 预约确认页（课程信息 + 训练目标选填 + 立即预约/加入候补）→ 预约详情（取消/签到/评价）→ 签到（扫码/手动确认）。

**评审**：
- ✅ 预约确认页**很简洁**（FREE 模式一键约，满员自动变"加入候补"），这是全站最贴合"免费预约"的页面。
- ❌ 团课预约也要求填"训练目标"（选填但字段多余，训练目标更适合私教场景）。
- ⚠️ **签到引导不足**：扫码签到需要扫"教室二维码"，但页面上没有明确说明到店后扫什么、二维码在哪，新用户会卡住。

**建议**：
- 团课预约去掉"训练目标"输入，私教预约保留。
- 签到页增加清晰的图文引导（"到店后请扫前台/教室的签到二维码，或点下方手动签到"）。

### 3.4 我的 Tab（`profile`）

**当前展示**：头像/昵称/等级 → 累计训练/积分/累计消费 → 10+ 个菜单项（我的预约/课包/训练/评估/评价/优惠券/积分/消息/邀请/反馈）→ 教练工作台入口（教练才显示）→ 退出/切换账号。

**评审**：
- ✅ 头像昵称手机号已支持微信授权（点头像换微信头像、编辑昵称、绑定手机号）。
- ❌ **菜单项过多（10+）且无分组**，层级深，"约课"之外的次要功能占了一半。
- ❌ "累计消费"在免费预约阶段显示为 0，意义不大。
- ❌ **教练工作台入口藏在列表底部**，新教练不好找。

**建议**：
- 菜单分组：**「我的约课」**（预约/训练/评估/评价）与 **「其他」**（券/积分/消息/反馈/邀请）分开，折叠次要项。
- 教练登录后，把"教练工作台"做成**顶部醒目入口**（而非底部菜单项）。

## 四、教练端评审（`coach-end` 分包）

**当前页面**：工作台（今日课程/待写记录/微信绑定）→ 课表 → 学员 → 学员档案 → 填训练记录 → 请假 → 调课 → 课程中心 → 方案。

**评审**：
- ✅ 数据权限已做（教练只看自己授课），这是符合真实工作室的关键点。
- ⚠️ 教练要维护的"运营内容"（首页教练团队、热门课程）**没有对应的小程序入口**，目前只能在 Web 后台改 —— 如果希望教练用小程序维护，这块是缺失的。
- ⚠️ 教练端是"分包"而非独立 Tab，入口不醒目（见 3.4）。

**建议**：确认"教练维护首页运营内容"是否走小程序；若走，需在教练工作台补入口；否则明确该能力仅后台可用，避免评审歧义。

## 五、繁琐点汇总（重点）

按"当前最影响体验"排序：

| 优先级 | 问题 | 位置 | 建议动作 |
|---|---|---|---|
| P0 | 新人体验专区"立即购买"与免费预约定位冲突 | 首页 | 弱化购买入口，强化"立即约课" |
| P0 | 新用户登录后无资料完善落地引导 | 登录后 | 首次登录直接弹"完善头像昵称"半屏 |
| P1 | 课程卡片显示"消耗课时"，暗示需购课 | 课程列表 | FREE 模式隐藏或改为"免费预约" |
| P1 | 团课预约要求填"训练目标" | 预约确认 | 团课去掉，私教保留 |
| P1 | 签到流程引导不足 | 签到页 | 加图文引导 |
| P1 | 首页 9 区块信息过载、预约不突出 | 首页 | 收敛区块，预约前置 |
| P2 | "我的"菜单 10+ 项无分组 | 我的 | 分组折叠次要项 |
| P2 | 教练工作台入口不醒目 | 我的 | 置顶为教练专属入口 |
| P2 | 快捷入口"立即预约/我的预约"混淆 | 首页 | 更名区分 |
| P3 | 教练维护运营内容缺小程序入口 | 教练端 | 明确走后台还是补小程序入口 |

## 六、评审修改建议（下一步怎么做）

1. **先定调**：当前阶段首页到底要不要展示"购买课包"？—— 如果免费预约是唯一路径，就把课包/支付相关入口整体降权或隐藏；如果还要试跑购买，就保留但明确区分"免费预约"与"购课包"两条路径。
2. **首屏重排**：首页以"预约"为唯一核心动作，其余内容做信息降噪。
3. **登录后引导**：新用户首次登录直接进入"完善资料"弹层（头像+昵称），一步完成微信授权。
4. **逐页按上表 P0→P1 改**，P2/P3 视资源排期。

> 说明：以上评审基于当前代码实态（页面结构、字段、入口），未涉及视觉美化与配色，仅针对"功能是否合适 + 是否繁琐"。如需，可在此基础上进一步出交互稿/线框图。
