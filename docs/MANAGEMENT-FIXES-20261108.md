## 修复内容

- 小程序课程编辑把可选分类统一为“小班课 / 私教课”，与 GROUP / PRIVATE 类型匹配；保存时复用或建立同名有效课程分类。保留旧分类、课程及预约记录，不做批量改名/迁移。旧体验课需在编辑时明确选择新分类。
- 管理表单增加真正的图片预览、加载失败提示、上传状态事件；上传中禁用保存。云托管较大的图片先调用官方 compressImage 等比缩小，再交给已有有界上传器；JPEG 压缩质量有效，PNG/GIF 若仍超出已有大小边界会被安全拒绝。图片准备与回调校验登录代次/服务目标，账号切换后不会继续提交旧选择。图片仍通过原有鉴权与 COS 私有存储/应用公开素材代理，不扩大桶权限。
- 教练编辑保存后读回持久化资料，列表展示头像；热门课程及首页教练团队返回页面重新加载，同时保留未保存的排序/勾选草稿并拒绝较旧的读取结果。
- Web 教练管理增加头像上传/显示，保存后等待列表读取完成；窗口重新获得焦点时刷新（编辑中的表单保留），不增加后台轮询。
- 首页热门/团队原实现逻辑删除后 insert，唯一键 course_id/coach_id 仍被软删除行占用，可复现重复保存或清空后重选时 DuplicateKeyException。改为事务内保留原有替换语义并 upsert 恢复唯一行。没有物理删除云数据，不需 DDL 或新增数据库权限。此问题与用户异常类型一致，但贴文没有具体 SQL，不能宣称已将那次异常精确归因到某个请求。
- 系统配置缓存失效延后至写事务提交后，避免提交前删除缓存导致另一请求读回旧值再缓存的常见窗口。没有声称为所有并发配置读取提供线性一致性。

有关联排课的课程/教练删除被 40900 拒绝属于保留历史的现有保护；仍应使用下架/停用或先处理未来排课，不改为绕过校验。
