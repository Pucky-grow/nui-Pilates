## 3. 页面、接口及关键数据流对应

| 页面 | 接口 | 数据流 |
|---|---|---|
| `admin/home` 工作台 | — | 入口导航 |
| `admin/studio` | `GET/PUT /api/coach-end/home/studio` | 读写 `system_config`（`studio.*`） |
| `admin/banners` + `admin/banner-edit` | `GET/POST/PUT/DELETE /api/coach-end/home/banners` + `POST /api/upload` | 读写 `banner` 表；缓存失效 `evictBannerCache` |
| `admin/hot-courses` | `GET/PUT /api/coach-end/home/hot-courses` | 读写 `home_hot_course` 表（全量替换） |
| `admin/team-coaches` | `GET/PUT /api/coach-end/home/team-coaches` | 读写 `home_team_coach` 表（全量替换） |
| `admin/proposals` | `GET /admin/course-proposals` + `approve/reject` | 读写 `course_proposal`；通过后生成正式课程 |
| `coach-end/course-edit` | `GET /api/courses/{id}` + `PUT /api/coach-end/courses/{id}/display` | 读写 `course` 展示字段（不可改价格/状态） |
| `coach-end/schedule-create` | `GET /api/coach-end/courses/my` + `GET /api/classrooms` + `POST /api/coach-end/schedules` | 选课程/教室 → 建排课 |
| `coach-end/schedule` | `GET /api/coach-end/schedules` + `POST .../cancel` | 查排课 / 取消排课 |

**新增后端接口（本轮）**：仅 `GET /api/classrooms`（只读教室列表）。其余全部复用。

## 4. 权限矩阵（后端实际授权）

| 能力 | ADMIN | STORE_MANAGER | COACH | MEMBER |
|---|---|---|---|---|
| 门店/Banner/热门课程/教练团队（`coach:home:*`） | ✅ 全量 | 视授权 | ❌ | ❌ |
| 课程方案审核（`manager:course:proposal:*`） | ✅ | ✅ | ❌ | ❌ |
| 编辑课程展示信息（归属校验 hasQualification） | ✅ | ✅ | ✅(本人) | ❌ |
| 创建/取消排课（教练强制本人 + 授课资格） | ✅ | ✅ | ✅(本人) | ❌ |
| 课程/排课全局管理（`course:*`/`schedule:*`） | ✅ | ✅ | ❌ | ❌ |

**权限落点**：后端 `@RequiresPerm`（PermissionAspect）+ `ScheduleService.forceCoachForCoachRole` + `cancel` 归属校验 + `CoachStudentService.hasServed` 数据范围校验。前端仅控制入口显示，不构成安全边界。

## 7. 已知问题及风险

| # | 问题 | 风险等级 | 说明 |
|---|---|---|---|
| 1 | `setHotCourses`/`setTeamCoaches` 为「全量删除+重插」，非幂等 | 低 | 重复提交结果一致（last-write-wins），单管理员操作风险低 |
| 2 | `/api/upload` 仅校验扩展名+大小，未校验文件魔数 | 低 | 可被伪图片绕过；建议后续加内容校验 |
| 3 | 管理员工作台未处理 token 过期（12h）的 401 友好提示 | 低 | 过期后仅弹「请求失败」 |
| 4 | 教练「编辑课程展示」的封面为上传URL，未做图片宽高比约束 | 低 | 展示可能变形 |
| 5 | 热门课程/教练团队「勾选顺序」依赖前端数组顺序，无拖拽排序 | 低 | 功能可用，体验一般 |
